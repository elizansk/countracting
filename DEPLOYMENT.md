# 🚀 Инструкции по деплою на Vercel

Сайт готов к публикации! Вот простые шаги для развертывания на Vercel.

## Вариант 1: Через веб-интерфейс Vercel (Самый простой)

1. **Откройте Vercel**: https://vercel.com
2. **Авторизуйтесь** через GitHub (или создайте аккаунт)
3. **Нажмите "New Project"**
4. **Выберите ваш репозиторий**: `elizansk/countracting`
5. **Нажмите "Import"**
6. **Нажмите "Deploy"** (переменные окружения не требуются)

Vercel автоматически:
- Обнаружит Next.js проект
- Установит зависимости
- Скомпилирует код
- Развернет на глобальной CDN

**Ваш сайт будет доступен в течение 2-3 минут!** 🎉

## Вариант 2: Через Vercel CLI

```bash
# 1. Установите Vercel CLI (если не установлен)
npm install -g vercel

# 2. Перейдите в папку проекта
cd ~/Documents/counteracting

# 3. Разверните проект
vercel

# Следуйте подсказкам и выберите ваш аккаунт GitHub
```

## Что происходит при деплое?

✅ Vercel автоматически:
- Обнаруживает Next.js 16.2.7
- Устанавливает все зависимости (framer-motion, react-query, etc.)
- Компилирует TypeScript
- Оптимизирует для продакшена
- Развертывает на глобальных серверах
- Настраивает SSL сертификат (HTTPS)
- Создает бесплатный домен `*.vercel.app`

## После деплоя

### Настройка собственного домена

1. Перейдите в **Settings** вашего проекта на Vercel
2. Выберите **Domains**
3. Добавьте ваш домен
4. Следуйте инструкциям для DNS конфигурации

### Автоматические обновления

Каждый `git push` в `main` ветку будет:
- Автоматически запустит build
- Развернет новую версию
- Обновит сайт в production

## Проверка перед деплоем

Перед деплоем убедитесь, что проект работает локально:

```bash
# Скомпилируйте проект
npm run build

# Запустите production версию локально
npm start

# Откройте http://localhost:3000
```

## Часто задаваемые вопросы

**Q: Нужно ли платить?**
A: Нет! Первый деплой на Vercel совершенно бесплатен. Бесплатный план включает достаточно ресурсов для большинства сайтов.

**Q: Где физически располагается сайт?**
A: На глобальных серверах Vercel в разных странах для максимальной скорости доступа.

**Q: Как отключить git integration?**
A: В Settings → Integrations → GitHub, можно отключить автоматические деплои.

**Q: Можно ли откатить изменения?**
A: Да, в Deployments вкладке можно увидеть историю и откатиться на старую версию.
