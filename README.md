# Норильск против мошенников

Статичный сайт-визитка о защите жителей Норильска от телефонного, интернет- и финансового мошенничества.

## Что внутри

- Главная страница с северной визуальной стилистикой Норильска.
- Статичный каталог схем мошенников без выдуманных номеров и сомнительных баз.
- Раздел “Как защититься” с памятками безопасности и мини-тестом риска.
- Страница официальных ресурсов.
- Локальный чат-помощник, который работает в браузере без отправки данных на сервер.

## Статичный формат

Проект настроен как статичный сайт:

```ts
// next.config.ts
const nextConfig = {
  output: "export",
  images: {
    unoptimized: true,
  },
};
```

После `npm run build` Next.js создаёт папку `out/`, которую можно разместить на любом статичном хостинге.

## Запуск

```bash
npm install
npm run dev
```

Локально сайт открывается по адресу:

```text
http://127.0.0.1:3000
```

## Сборка

```bash
npm run build
```

Готовые статичные файлы появятся в:

```text
out/
```

## GitHub Pages

Сайт можно публиковать через ветку `gh-pages`: собрать проект, отправить содержимое папки `out/` в корень ветки и выбрать её источником GitHub Pages.

Для репозитория `elizansk/countracting` публичный адрес будет:

```text
https://elizansk.github.io/countracting/
```

В настройках GitHub нужно выбрать Pages source: **Deploy from a branch**, ветку `gh-pages` и папку `/ (root)`.

## Важно

Сайт не публикует непроверенные реальные номера, аккаунты или сайты как “опасные”. Материалы носят информационный характер и не заменяют обращение в банк, МВД или другой официальный орган.
